
# Pipelines

This folder contains **pipeline scripts that orchestrate end-to-end workflows** in the recommendation system.

A pipeline connects multiple components of the project (ingestion, preprocessing, models, and storage) to produce a final output such as recommendation files or evaluation results.

Typical pipeline steps may include:

- loading input data
- preprocessing or preparing text/data
- computing embeddings or similarity scores
- generating recommendations
- saving recommendation outputs

## Rule of thumb

Put code here if it **coordinates multiple steps of the system into a workflow**.
